# Data Quality and Validation in ETL – Assignment

## About the Assignment

This repository contains my assignment on **Data Quality and Validation in ETL**.

The assignment covers important concepts related to data quality, data validation, duplicate data, business rules, SQL-based duplicate detection, and referential integrity.

## Assignment Topics

1. Data Quality in ETL pipelines
2. Impact of poor data quality
3. Causes of duplicate data
4. Exact, partial, and fuzzy duplicates
5. Data validation during transformation
6. Business rules for data validation
7. Detecting duplicate business keys using SQL
8. Enforcing Referential Integrity
